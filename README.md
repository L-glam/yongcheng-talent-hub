# 永城市四套班子人才库

一个本地运行的人才库网页，用于查看和整理永城市委、市政府、市人大常委会、市政协班子成员的公开履历资料。

## 使用方式

直接双击 `index.html` 即可在浏览器中打开，不需要安装任何依赖，也不需要联网。

## 分享给别人

只发 `index.html` 是不够的，因为它还需要同目录下的 `styles.css`、`data.js`、`app.js`。推荐两种方式：

1. 发单文件版：`yongcheng-talent-hub.html` 已把样式、脚本和数据全部内嵌，别人下载后用浏览器打开即可，无需解压。
2. 发压缩包：把整个 `yongcheng-talent-hub` 文件夹压缩后发送，接收方解压后双击 `index.html`。

QQ 发送版位于 `永城市四套班子人才库-发送版`，内含「永城市四套班子人才库.html」和「打开说明.txt」，直接发送压缩包或两个文件均可。

如果希望所有人在手机上直接通过网址访问，需要把文件夹部署到静态托管平台（如 Gitee Pages、GitHub Pages、Netlify、Vercel），拿到公网链接后再分享。

更新单文件版：修改 `data/people.csv` 后依次运行

```text
python scripts/build_data.py
python scripts/bundle_single.py
```

## 局域网访问（不公开到公网）

适合单位内部人员通过手机或电脑直接访问：

1. 双击 `start_lan_server.bat` 启动本地服务；
2. 首次使用请右键 `allow_firewall.bat`，选择“以管理员身份运行”，放行 TCP 8765 端口；
3. 查看本机局域网 IP：命令行执行 `ipconfig`，找到类似 `192.168.x.x` 或 `10.x.x.x` 的 IPv4 地址；
4. 同一 WiFi/局域网内的设备，在浏览器打开 `http://本机IP:8765/` 即可访问。

注意：电脑需要保持开机且不睡眠，服务才会持续在线；局域网内任何能连到该网络的人都可访问，请只分享给可信人员。

页面支持：

- 按班子、正职/副职、关键词筛选和检索
- 按出生年月、姓名、履历完整度排序
- 点击人员卡片查看成长轨迹、所获荣誉、晋升路径和资料来源
- 导入 CSV 更新数据，或导出当前数据为 CSV

## 数据结构

数据维护入口是 `data/people.csv`，用 Excel 打开即可编辑。编辑后有两种方式生效：

1. 在页面右上角点击“导入 CSV”，选择编辑好的文件；
2. 或运行 `python scripts/build_data.py` 重新生成 `data.js`，刷新页面。

常用字段约定：

- `teams`：所属班子，多个用 `/` 分隔，取值：`市委`、`市政府`、`市人大常委会`、`市政协`
- `current_roles`：现任职务，多个用 `；` 分隔
- `career`：任职经历，条目用 `；` 分隔，每条格式为 `起止时间|职务|补充说明`
- `honors`：所获荣誉，条目用 `；` 分隔，每条格式为 `时间|荣誉名称|补充说明`
- `promotion`：晋升路径，用 `→` 连接
- `sources`：资料来源，条目用 `；` 分隔，每条格式为 `来源名称|链接`

首次生成 CSV 可运行 `python scripts/seed_data.py`。

## 数据说明

当前数据整理时间：2026-08-02。资料来源于永城市人民政府门户网站、百度百科、商丘市政府网等公开渠道，仅供内部参考；涉及人员职务、任免和履历的信息请以官方最新公开文件为准。

部分成员（尤其新任市委常委、人大副主任、政协副主席）公开履历较少，`career`、`honors`、`promotion` 等字段留空，可在 CSV 中直接补充。
